# MLBenchArchive-app

This is the project that inherits papers with code. 

## Local development

- Use `make launch-local` (repo root) to start the full stack (frontend + backend API).
- You can also run `make launch-local` or `./scripts/local.sh` from the repo root (same behavior).
- Frontend-specific setup and **HTTPS (mkcert over SSH)** instructions are in `mlbench/app/README.md`.
